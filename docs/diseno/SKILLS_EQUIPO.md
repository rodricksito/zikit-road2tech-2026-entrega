## Qué usar primero

**Conservar y ampliar las pruebas actuales del repositorio.** Usar las skills incorporadas de Claude si están disponibles y dejar las externas como opciones; la instalación no debe bloquear #5 ni #22. Estas opciones no requieren migrar de IA, framework o arquitectura.

Para comprobar causalidad, falsas alarmas, desplazamiento de fechas y memoria, la prioridad sigue siendo ejecutar casos reproducibles y registrar resultados. En las fuentes revisadas no se identificó una skill especializada oficial que justifique sustituir ese trabajo. Tampoco se recomienda incorporar ahora skills de Claude API, MCP, nube o Figma: no resuelven el bloqueo actual del camino C.
